AI usage

How I use coding agents, in numbers.

From 1 Nov 2026 to 20 Nov 2026 I ran 486 agent threads. They processed 11.03 billion tokens and wrote 40.2 million. I made the architecture decisions, reviewed the code and decided what shipped. The figures come from T3 Code, the tool I run the agents in.

Totals

What the numbers mean.

  • 40.2MOutput: what the agents wrote
  • 139.9MNew input: what they read for the first time
  • 11.03BProcessed in total, mostly cached re-reads

New input is input that was not already cached. Most of the processed total is cached: earlier parts of a conversation that an agent reads again on later turns.
