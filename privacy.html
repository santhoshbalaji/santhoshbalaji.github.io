01 / Measurement

What is measured

Cloudflare Web Analytics provides aggregate page views, visits, referring sites, broad country, device category, browser, operating system, and page-performance metrics. These measurements help identify whether the site works well and which public pages are useful.

02 / Boundaries

What is not collected

The portfolio code does not set analytics cookies or analytics identifiers in local or session storage. It does not collect names, email addresses, precise location, full query strings, or interaction histories. Analytics are not used for advertising, profiling, or remarketing.

03 / Operation

How it works

A lightweight Cloudflare beacon is loaded only on santhoshbalaji.cloud. Cloudflare states that Web Analytics does not use client-side state or fingerprint individuals. The dashboard is private, and this site does not export individual-level analytics records.

Read Cloudflare’s Web Analytics documentation ↗.

04 / Choice

Your browser signal is respected

If your browser sends Global Privacy Control or Do Not Track, this site does not load the analytics beacon. You can also block the beacon with browser privacy tools without losing any site functionality.

05 / Retention

Short-lived by default

Cloudflare currently retains unsampled beacon data for seven days and makes aggregate Web Analytics reports available for the previous six months. This site does not create its own analytics database or keep separate visitor-level exports.
